# Nexo + QMarco

Tu espacio creativo. Aplicaciones de escritorio nativas en Rust, con diseño oscuro adaptable a tu ventana.

## Descargar

[**Ir a la última versión →**](https://github.com/Luarkcm/nexo-releases/releases/latest)

Descarga el instalador de **Nexo** para tu sistema. Ábrelo y pulsa **Instalar QMarco**. Nexo también incluye QMarco para instalarlo sin conexión.

| Sistema | Archivo |
|---|---|
| Mac con chip Apple Silicon | `Nexo-macOS-arm64.dmg` |
| Mac Intel | `Nexo-macOS-x86_64.dmg` |
| Windows de 64 bits | `Nexo-Windows-x64-Setup.exe` |
| Ubuntu 22.04 o posterior | `Nexo-Linux-amd64.deb` |
| Linux portable | `Nexo-Linux-x86_64.tar.gz` |

En Mac, arrastra Nexo a Aplicaciones. En Windows, sigue el asistente. En Linux, instala el paquete DEB o extrae la versión portable con sus bibliotecas gráficas disponibles.

## QMarco

Antes llamado Marquiño. Coloca marcos distintos según la orientación, ajusta su ancho hasta el 100 %, mejora automáticamente luz y color sin tocar el marco y exporta tus fotografías por lote. Los originales se conservan y el procesamiento es local.

## Nexo

Busca, instala y abre tus aplicaciones desde una biblioteca con vistas de tarjetas y lista. Comprueba nuevas versiones al abrir y cada 30 minutos mientras permanece abierto. Puedes desactivar las actualizaciones automáticas o restaurar la versión anterior.

Los ZIP y `catalog.json` de cada versión son para el actualizador. Nexo se actualiza descargando su instalador.

Los instaladores actuales no incluyen firma comercial de Windows ni notarización de Apple.

Este repositorio distribuye instaladores y catálogos. El código fuente se mantiene privado.
